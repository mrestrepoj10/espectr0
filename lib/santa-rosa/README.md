# Santa Rosa de Cabal seismic-microzonation research dossier

Status: **adoption lineage and warnings verified; municipal spectrum activation blocked**.

Acuerdo 028 de 2000 incorporates Acuerdo 012 de 2000, names seven response zones, requires an approximately 200 m transition strip on each side using the more demanding adjacent acceleration, and says the spectrum does not replace project geotechnical investigation. It also says Aa/Av are not valid with the municipal spectra and points to Am/An equivalents.

Acuerdo 076 de 2013 is a separate later municipal instrument. It preserves the PBOT's other provisions and references NRS-10 together with the adopted municipal microzonation for selected height rules. It does not republish a complete harmonized technical model.

The primary Acuerdo 012 technical package, coefficient tables, Am/An values, hazards, return periods, damping, equations and branch policy were not located. The F3 matrix therefore covers one direct regulatory-status statement at 100%, while the proposed spectrum matrix is exactly empty. No engine, UI, registry, map, GIS, coordinates or automatic zone selection is added. `verify_official_sources.py` re-checks locally supplied official bytes and the exact warning/compatibility statements. Sources remain external-only and activation is blocked.
