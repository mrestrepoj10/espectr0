# Cali oracle

This oracle is independent of any future product engine. It reads only the
double-entered coefficient input and evaluates formulas with 50-digit Python
`Decimal` arithmetic.

The design, limited-safety, and site-specific-minimum spectra have complete
three-branch records. Damage-threshold records intentionally cover only
`T > Tcd`: Decreto 0158's graph needs `A0d` and `Fa` for earlier branches, but
Table 4 supplies neither. The oracle therefore exposes the gap and blocks
activation instead of borrowing values from NSR-10 or another city.

Tabulated breakpoints select branches. Residuals at those breakpoints expose
rounding in published coefficients and must not be normalized away.
