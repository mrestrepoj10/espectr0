# Armenia independent oracle

This is deliberately a **negative oracle**. The locked official record does not establish an adopted, NSR-10-harmonized Armenia option × hazard matrix or complete formula set, so numerical witnesses would manufacture authority that the sources do not provide.

`generate_oracle.py` reads only `oracle-input.json` when it builds the five expected decisions. It imports no TypeScript, production engine, generated manifest, or canonical row. After the decisions are built, it hashes the canonical bytes only to seal the review set in `locks.json`; that hash does not influence any decision.

The permitted outcomes are typed rejections for legacy, unadopted, unknown and site-specific municipal requests, plus continuation through the national NSR-10 building workflow. A future numerical oracle requires the adopted primary technical package first.

Run:

```powershell
python lib/armenia/oracle/generate_oracle.py --check
```
