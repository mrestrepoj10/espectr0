# Armenia independent oracle

This is deliberately a **negative oracle**. The locked official record confirms the historical applicability of Decreto Municipal 079, but its primary numerical annex does not establish a complete option × hazard matrix or formula set, so numerical witnesses would manufacture authority that the sources do not provide.

`generate_oracle.py` reads only `oracle-input.json` when it builds the five expected decisions. It imports no TypeScript, production engine, generated manifest, or canonical row. After the decisions are built, it hashes the canonical bytes only to seal the review set in `locks.json`; that hash does not influence any decision.

The permitted outcomes are a typed missing-annex rejection for the historical model, a context-only rejection for the delivered 2025 update, typed rejections for unknown and site-specific requests, plus continuation through the national NSR-10 building workflow. A future numerical oracle requires the primary Decreto 079 technical package first.

Run:

```powershell
python lib/armenia/oracle/generate_oracle.py --check
```
